# 🎨 AI Image Generation with Stable Diffusion

This project demonstrates the use of a **pre‑trained Stable Diffusion model** to generate high‑quality images from text prompts.  
The model runs on **Google Colab** with a free T4 GPU, using the `diffusers` library from Hugging Face.
